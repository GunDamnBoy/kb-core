# 怎麼跑這兩支探測（給有網路的機器）

**為什麼要你跑**：Cowork 這一側的對外連線只通 GitHub 與 PyPI，
TWSE／TAIFEX／FRED／Stooq 全部不通（雲端容器與 device bash 兩邊都試過，`curl` 皆回 000）。
下面兩支要在**你的 Mac 終端機**跑，不是在對話裡跑。

程式在 `~/kb-core/scripts/sentiment/`。

## 前置

```bash
python3 -m pip install --user numpy pandas scipy
```

## 第 1 步：台股籌碼（最重要的一步）

```bash
cd ~/kb-core/scripts/sentiment
export SENT_CACHE=~/sent-cache
python3 tw_probe.py --fetch
```

**會跑很久**（逐日補 2014 起的融資餘額、當沖占比、外資期貨未平倉，約 3,000 個交易日 ×3 支端點，
每次間隔 0.25–0.3 秒 → 大約 40–60 分鐘）。**中途可以 Ctrl-C，快取會保留，再跑一次會接著補。**
每 200 筆存一次檔，畫面會印進度。

抓完跑分析：

```bash
python3 tw_probe.py --analyze
```

把整段輸出貼回來。特別注意這幾行：

- `fut_oi: 有值 N 筆` —— **N 小於 100 就代表外資期貨未平倉拿不到歷史**，
  那一項要降為候補、用三大法人現貨買賣超遞補。這是設計書第九節的第一個待驗項。
- `可用成分：…（設計書列 3 項，本次 N 項）`
- T3 那行的「合成有加值／**合成沒有加值**」

## 第 2 步：觸發器 ＋ CAPE 分層

```bash
python3 trigger_probe.py
```

這支快（只抓 FRED 幾條序列與兩個 GitHub 檔），幾分鐘內跑完。要看的是：

- **「歷史上同時亮 ≥N 盞的月數」** —— 這是設計書第十三節要的那個數字。
  我的預期是 ≥3 盞大約落在 2000、2007、2022 附近，也就是 **n≈3**。
  若真的只有 3 段，分層結論就只能當「引用」不能當「證明」。
- 極端恐懼在「觸發器 0–1 盞」與「≥2 盞」兩組之間，**12 個月中位報酬與最差值差多少**。
  差得夠開，第十三節的假設就成立；差不開就整組退役。

## 若某支失敗

**貼錯誤訊息回來，不要自己改參數重跑。** 這兩支的設計是
「抓不到就空著、不插補」，所以失敗會明講失敗；
真正危險的是有人為了讓它跑完而把門檻放寬——那會產出一個看起來很合理的假結果。

## 這兩步之後

- 台股籌碼**有訊號** → 接著做美股的週頻部位層（COT／ICI／AAII），那也是「部位」不是「價格」。
- 台股籌碼**也沒有訊號** → 照設計書第十節辦：不發布合成分數，
  儀表板降級成誠實呈現原始序列。**一個沒有前瞻資訊的 0–100 分數比沒有分數更糟，
  因為它看起來像結論。**

# 每日五圖｜取數眉角

**這份在 SKILL 第 3 步才需要讀。** 每一條都是實測撞出來的，
而其中一半的失效方式是安靜的 —— 那些用 **粗體** 標出來。

數字（限流、代理、歷史深度、單位換算）在 `chart/anchors.json`，這裡不抄。

## 允許的來源

| 來源 | 用途 | 金鑰 |
|---|---|---|
| FRED | 總經、利率、利差、信用、匯率、通膨預期 | `FRED_API_KEY` 或 `~/.config/fred/api_key`，**不進版控** |
| Tiingo | 美股個股與 ETF 日線 | `TIINGO_API_KEY` 或 `~/.config/tiingo/api_key`，**不進版控** |
| 證交所、櫃買 | 台股日收盤、籌碼、台灣總經 | **免金鑰、官方端點** |
| 世界銀行／IMF／EIA | 跨國、能源實體數據 | 官方 JSON／CSV |
| 公司財報、法說簡報 | 個別公司數字 | 原始文件，**不引用二手轉述** |

**一律不使用付費牆內的圖或數據。** 取論點沒問題，把對方的數字當我們的資料來源不行。

## 三個在這台機器上成立的事實

- **Yahoo 對本機是永久封鎖。** 2026-08-16 複測：兩天後、單一標的、零流量，
  第一個請求仍 429。預抓每天只試一條當哨兵 ——
  **全部不試就再也不會發現它恢復，全部都試就每天白耗好幾分鐘。**
  等價序列對照（`^VIX`→`VIXCLS`、`^GSPC`→`SP500` 等）在 `fetch.py`；
  台股個股與美股 ETF **沒有 FRED 等價**。
- **`fredgraph.csv` 在發布機上連不通**（`Errno 60`），而 `api.stlouisfed.org` 正常。
  **在這台機器上，退路才是壞的那一條** —— FRED API key 是這條線的唯一活路。
  若某輪回報「無 API key，走 fredgraph 退回端點」，**先確認那輪跑在沙箱還是發布機**。
- **FRED 一次只能抓一條序列。** `fredgraph.csv?id=A,B` 回傳的是 zip。

## 安靜失敗的那些

- **櫃買被節流時回空 body，不是錯誤碼。** 空不是「沒有資料」，是被擋。
  取數層要重試並在最後誠實拋錯，**不回空序列**。
- **證交所日期送錯不會報錯，會安靜回最近一個交易日。** 務必核對回傳的 `title`。
- **櫃買的成交量欄位名稱會隨年代改變**（近年「成交張數」、2016 年「成交仟股」），
  要讀 `flagField` 判單位 —— 與融資餘額「仟元 vs 元」同類，
  **差 1,000 倍而數字看起來都像個數字**。
- **Yahoo 期貨日線會整日空值**（2026-08-06 實測六支全空）。
  **空值那天直接跳過，不要內插、不要拿前一日頂替**，並寫進 `window.note`。
  **不要照原樣出圖再用「轉倉」搪塞。**
- **民國年轉換錯了不會報錯**，只會讓整條序列偏到 1911 年代。

## 兩件容易被弄反的事

- **回空殼與被封鎖是兩件事，處置相反。** 前者換讀法、後者換來源。
  把前者誤判成後者，等於白白放棄一個可用的來源 —— Bloomberg Graphics 就這樣被閒置了七天。
- **同樣是 429，成因可能完全不同。** 第一個請求就 429 → 等再久也不會好；
  打了一陣子才 429 → 那是該等的那種。**分辨方式是看它第幾次請求才出現。**

## 瀏覽器路徑

- **`navigate` 到 JSON 網址會被 Chrome 當檔案下載**；改 `fetch` 之後**跨子網域會被 CORS 擋**。
  正解是**先 `navigate` 到同網域頁面再 `javascript_tool` fetch**。
- **證交所／櫃買不允許跨源，但同源可用。** 先前把限制寫成「CORS 使瀏覽器備援無效」是寫過頭了 ——
  **把限制寫得比實際寬，會讓人在真正需要備援時直接放棄一條可用的路。**
- **瀏覽器備援需要人在場，無人值守輪次實際上不可用。** 2026-08-14 那輪就因為當下沒有 Chrome
  而完全沒有產出。所以 `about.data_path` 走到 `browser` 是**該響的**，不是降級。

## 題材來源的可取用性

| 來源 | 狀況 | 處置 |
|---|---|---|
| Charts of the Day | 可取，最好抓 | 首頁即封存索引，`/p/<slug>` 免登入可讀全文 |
| Bloomberg Graphics | **回空殼**（前端渲染，不是被擋） | 走瀏覽器：`navigate` 後取頁面文字 |
| Economist Graphic Detail | 抓取層封鎖 | **不要繞**，換來源 |
| Reuters Graphics | 抓取層封鎖 | 同上 |
| DB Research CoTD | 可取但頁面很大 | 清單頁通常夠用 |

## 代理

沒有免費來源的指數用 ETF 代理，對照表在 `anchors.proxies`。

**代理必須在 `series_spec` 明寫，不由取數層自動替換。**
曾經寫成「`^SOX` 取不到就改抓 `SOXQ`」，那會把 ETF 的資料寫進指數的快取，
**圖上標的是指數、數字卻是 ETF**。**替換要是一個有意識的決定，不是取數層的靜默行為。**

用代理時錨點措辭要跟著限縮（歷史深度在 `anchors.history_limits`）——
`SOXQ` 只回到 2021 年成立，**不可寫「歷史上」或「十年分位」**。
